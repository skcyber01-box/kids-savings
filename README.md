# กระปุกเก้ากับเกต 🐷

เว็บบันทึกเงินออมแบบ 3 กระปุก (ใช้ / ออม / แบ่งปัน) ให้เก้ากับเกตบันทึกเองบนแท็บเล็ต
พ่อแม่ยืนยันรายการ จ่ายดอกเบี้ย และตั้งค่าได้ในโหมดพ่อแม่

## โครงสร้างไฟล์
```
index.html      หน้าเว็บทั้งหมด (ไม่ต้อง build)
api/data.js     Serverless function สำหรับอ่าน/บันทึกข้อมูล (Upstash Redis)
package.json
```

## วิธี Deploy บน Vercel (ประมาณ 10 นาที)

1. **อัปโหลดขึ้น GitHub** – สร้าง repo ใหม่ (แนะนำแบบ Private) แล้ว push ทั้งโฟลเดอร์นี้
2. **Import เข้า Vercel** – vercel.com → Add New → Project → เลือก repo
   - Framework Preset: **Other** · Build Command: เว้นว่าง · Output Directory: เว้นว่าง
3. **เพิ่มฐานข้อมูล** – ในโปรเจกต์ → แท็บ **Storage** → Create/Connect → เลือก **Upstash (Redis)** แผนฟรี → Connect กับโปรเจกต์นี้
   - Vercel จะตั้ง environment variables `KV_REST_API_URL` และ `KV_REST_API_TOKEN` ให้อัตโนมัติ
   - ถ้าสร้าง Upstash เองที่ upstash.com ให้ใส่ `UPSTASH_REDIS_REST_URL` และ `UPSTASH_REDIS_REST_TOKEN` แทน
4. **(แนะนำ) ตั้งรหัสครอบครัว** – Settings → Environment Variables → เพิ่ม `FAMILY_KEY` = รหัสที่ต้องการ
   เพื่อไม่ให้คนนอกที่รู้ลิงก์อ่านหรือแก้ข้อมูลได้ แท็บเล็ตจะถามรหัสนี้ครั้งแรกครั้งเดียว
5. **Redeploy** – Deployments → ⋯ → Redeploy (ให้ env ใหม่มีผล)
6. **เปิดบนแท็บเล็ต** – เปิดลิงก์ใน Safari/Chrome → แชร์ → "เพิ่มไปยังหน้าจอโฮม" จะได้ไอคอนเหมือนแอป

> ถ้ายังไม่ได้ทำขั้นตอนที่ 3 เว็บยังใช้งานได้ แต่จะเก็บข้อมูลเฉพาะในเครื่องนั้น (มีแถบเตือนสีเหลือง)

## ค่าเริ่มต้น
| รายการ | ค่า |
|---|---|
| รหัสพ่อแม่ | `1234` (เปลี่ยนในโหมดพ่อแม่ → ตั้งค่า) |
| สัดส่วนกระปุก | ใช้ 50% / ออม 40% / แบ่งปัน 10% |
| ดอกเบี้ยพ่อ | 2% ต่อเดือน จากกระปุกออม |
| งานบ้าน | ล้างรถ 40 · กวาดบ้าน 10 · ถูบ้าน 10 · ตากผ้า 10 · ช่วยทำอาหาร 10 |

## เป้าหมายใหญ่ (ค่าเริ่มต้น: ไปเที่ยวจีนด้วยกัน)
| รายการ | ค่า |
|---|---|
| วันครบกำหนด | 1 พ.ค. 2027 (2570) |
| เป้าครอบครัว | 60,000 บาท = ลูกคนละ 15,000 + พ่อแม่ 30,000 |
| เป้าของลูกแต่ละคน | 15,000 บาท (รวมเงินสมทบ) |
| พ่อแม่สมทบ | 1 เท่า (ลูกหยอด 20 → พ่อแม่สมทบ 20) และหยุดสมทบอัตโนมัติเมื่อลูกครบเป้า |

- **ลูก** กด "หยอดเงินเข้าเป้านี้" แล้วย้ายเงินจากกระปุกออมหรือกระปุกใช้ ระบบโชว์ยอดสมทบให้เห็นทันที
- **ออมเข้าเป้าอัตโนมัติ** (ตั้งรายคนในโหมดพ่อแม่ → เป้าหมายใหญ่ → แก้ไขเป้าหมาย) ส่วนออมของรายรับใหม่จะเข้าเป้าใหญ่พร้อมเงินสมทบทันที เหมาะกับลูกคนเล็ก
- **พ่อแม่** บันทึกเงินส่วนของพ่อแม่ได้ที่แท็บเป้าหมายใหญ่
- แก้ไขชื่อ วันครบกำหนด ยอดเป้า อัตราสมทบ หรือเพิ่มเป้าหมายใหม่ได้ เป้าที่ปิดแล้วจะเก็บประวัติไว้

## 📷 ถ่ายรูปนับเงิน (ไม่บังคับ)
ปุ่ม "ถ่ายรูปเงิน ให้ช่วยนับ" อยู่ในหน้าเงินเหลือจากโรงเรียน เงินพิเศษ และหยอดเป้าใหญ่
ระบบส่งรูปให้ Claude นับเหรียญและแบงก์ไทย แล้วเติมยอดให้ เด็กแก้ยอดเองได้ก่อนบันทึก

**วิธีเปิดใช้**
1. สมัครและเติมเครดิตที่ console.anthropic.com → API Keys → Create Key
   (เป็นบัญชี API แยกจาก Claude Pro/Max คิดค่าใช้จ่ายตามการใช้งาน)
2. Vercel → Settings → Environment Variables → เพิ่ม `ANTHROPIC_API_KEY` = คีย์ที่ได้
3. (ไม่บังคับ) `ANTHROPIC_MODEL` ถ้าต้องการเปลี่ยนโมเดล ค่าเริ่มต้นคือ `claude-sonnet-5-5`
4. Redeploy

**เคล็ดลับให้นับแม่น**
- วางเงินบนพื้นเรียบสีเรียบ ไม่ให้เหรียญซ้อนกัน แบงก์คลี่ให้เห็นทั้งใบ
- ถ่ายจากด้านบนตรงๆ ในที่มีแสงพอ
- รูปถูกย่อในเครื่องก่อนส่ง และไม่ถูกเก็บไว้บนเซิร์ฟเวอร์ ระบบเก็บไว้แค่ผลที่นับได้
- ในหน้ารอยืนยัน พ่อแม่จะเห็นป้าย 📷 พร้อมรายละเอียดที่นับได้ ถ้าลูกแก้ยอดเอง จะขึ้นว่า "(ลูกแก้ยอด)"

## การใช้งาน
**ลูก** – แตะชื่อตัวเอง → กดงานบ้านที่ทำ / เงินเหลือจากโรงเรียน (กดเหรียญ-แบงก์) / ใช้เงิน → รายการขึ้นสถานะ "รอพ่อแม่ยืนยัน"
**พ่อแม่** – โหมดพ่อแม่ (ใส่รหัส) →
- *รอยืนยัน*: อนุมัติหรือไม่อนุมัติรายการ
- *สรุป & ดอกเบี้ย*: ยอดแต่ละกระปุก รายรับ-รายจ่ายเดือนนี้ ปุ่มจ่ายดอกเบี้ย (เดือนละครั้ง)
- *บันทึกเอง*: รายรับ ใช้เงิน ย้ายเงินระหว่างกระปุก ปรับยอดหลังวันนับเงิน
- *ตั้งค่า*: งานบ้าน/ราคา สัดส่วนกระปุก ดอกเบี้ย รหัส ชื่อ-รูปลูก สำรองข้อมูล JSON/CSV

## หมายเหตุ
- ข้อมูลสำรองอัตโนมัติวันละครั้งใน Redis (เก็บ 90 วัน, key `kids-savings:state:backup:YYYY-MM-DD`)
- หลายเครื่องใช้พร้อมกันได้ ระบบรวมรายการให้อัตโนมัติและดึงข้อมูลใหม่ทุก 30 วินาที
- รหัสพ่อแม่ 4 หลักกันแค่เด็กกดเข้าโหมดพ่อแม่ ไม่ใช่ระบบความปลอดภัยเต็มรูปแบบ ความปลอดภัยของข้อมูลมาจาก `FAMILY_KEY`
